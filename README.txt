# NIKASTRA — Clothing Website

NIKASTRA is a responsive front-end clothing storefront built from the supplied DRIFT template.

## Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` directly or use VS Code + Live Server.
3. Replace the CSS placeholder visuals with real NIKASTRA product photographs when available.

## Main edits
- Brand/content: `index.html`
- Products and prices: product cards in `index.html`
- Design/colors: `style.css`
- Cart, quick view, menu and newsletter interactions: `script.js`

No build system or framework is required.
